# BST

**BST** - или же, **двоичное дерево поиск**, это структура данных, которая представляет из себя, соответственно, двоичное дерево, для которого выполняются следующие дополнительные условия:
- оба поддерева - левое и правое - являются двоичными деревьями поиска;
-  у всех узлов _левого_ поддерева произвольного узла X значения ключей данных _меньше либо равны_, нежели значение ключа данных самого узла X;
-  у всех узлов _правого_ поддерева произвольного узла X значения ключей данных _больше_, нежели значение ключа данных самого узла X.

Проще говоря, это дерево, для которого сохраняется структура, все что *слева* -  меньше или равно, а *справа* строго больше. И это правило применяется для каждого узла дерева, а не только корня. 
Можно думать так:
- идёшь по дереву
- если число меньше → идёшь налево
- если больше → направо

## Основные операции

>> P.S прежде чем переходить к основным операциям BST, рекомендуется ознакомиться с основными элементами дерева. (лист, корень, узел). А также прочитать краткую теорию о том, что из себя представляют сами деревья и их теоретические особенности от обычных графов.

1. **FIND (K) - найти элемент**
	  Идём от корня:
		 если нашли → ок
		 если K меньше → идём влево
		 если больше → вправо
	  Проще говоря, это тот же бинарный поиск, но по дереву
2. **INSERT(K, V) - вставить элемент**
	  Идём как при поиске, пока не упрёмся в `NULL`, и вставляем туда.
3.  **REMOVE(K) - удаление**
	   Eсли узел **лист** → просто удалили
	   если **один ребёнок** → поднимаем ребёнка
	   если **два ребёнка** →  берём ближайшее число (обычно минимум справа или максимум слева) и заменяем

## Для чего нужен BST?

В первую очередь, эта структура создана исключительно для того, чтобы быстро вставлять, находить и удалять элементы. Если мы проделаем подобные операции на обычном массиве (`vector`), общая асимптотика будет линейной, или же $O(n)$, BST же позволяет ускорить данный процесс до:
- поиск → $O(\log n)$
- вставка → $O(\log n)$
- удаление → $O(\log n)$
Что, несложно заметить, в бесконечности сильно быстрее :)

## Реализация

``` C++
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int val;
    Node *l, *r;
    Node(int v) : val(v), l(NULL), r(NULL) {}
};

struct BST {
    Node* root = NULL;

    Node* insert(Node* t, int x) {
        if (!t) return new Node(x);
        if (x <= t->val) t->l = insert(t->l, x);
        else t->r = insert(t->r, x);
        return t;
    }

    Node* findMin(Node* t) {
        while (t && t->l) t = t->l;
        return t;
    }

    Node* erase(Node* t, int x) {
        if (!t) return NULL;
        if (x < t->val) t->l = erase(t->l, x);
        else if (x > t->val) t->r = erase(t->r, x);
        else {
            if (!t->l) return t->r;
            if (!t->r) return t->l;
            Node* m = findMin(t->r);
            t->val = m->val;
            t->r = erase(t->r, m->val);
        }
        return t;
    }

    void inorder(Node* t) {
        if (!t) return;
        inorder(t->l);
        cout << t->val << " ";
        inorder(t->r);
    }
};

int main() {
    BST t;

    vector<int> a = {10,15,16,13,12,14,9,8,10,10,17};
    for (int x : a)
        t.root = t.insert(t.root, x);

    t.inorder(t.root);
    cout << "\n";

    t.root = t.erase(t.root, 13);
    t.inorder(t.root);
}
```
