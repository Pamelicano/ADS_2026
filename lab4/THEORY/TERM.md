# ТЕРМИНЫ

- **Граф** — множество вершин (узлов) и рёбер (связей) между ними. Обозначается как $G=(V,E)$ где:
    
    - $V$— множество вершин,
        
    - $E$ — множество рёбер.
        
- **Вершина (узел)** — элемент графа, может представлять объект, точку, состояние и т.д.
    
- **Ребро** — связь между двумя вершинами.
    
    - **Ориентированное ребро** (дуга) — имеет направление (например, из A в B).
        
    - **Неориентированное ребро** — не имеет направления (A соединено с B).
        
- **Смежные вершины** — вершины, соединённые ребром.
    
- **Степень вершины**:
    
    - В **неориентированном графе** — количество рёбер, инцидентных вершине.
        
    - В **ориентированном графе**:
        
        - **Входящая степень** — количество входящих рёбер.
            
        - **Исходящая степень** — количество исходящих рёбер.
            
- **Путь** — последовательность рёбер, соединяющих ряд вершин.
    
- **Цикл** — путь, начинающийся и заканчивающийся в одной и той же вершине, без повторений рёбер или (в простом цикле) вершин.
    
- **Простой путь / простой цикл** — путь / цикл без повторяющихся вершин (кроме начала и конца у цикла).
    
- **Связный граф** — неориентированный граф, где существует путь между любой парой вершин.
    
- **Сильно связный граф** — ориентированный граф, в котором для любой пары вершин uuu и vvv существует путь как из uuu в vvv, так и из vvv в uuu.
    
- **Дерево** — связный ацикличный граф.
    
- **Взвешенный граф** — граф, у рёбер которого есть веса (например, расстояние, стоимость и т.п.).
    
- **Матрица смежности** — таблица, отображающая наличие рёбер между вершинами.
    
- **Список смежности** — структура, где для каждой вершины перечислены все соседние вершины.
